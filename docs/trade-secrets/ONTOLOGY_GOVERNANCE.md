# Ontology Governance

Confidential internal material.

The specialty ontology is a protected operating asset:

- symptom chips
- modifiers
- pertinent negatives
- observations
- interventions
- reassessment prompts
- escalation patterns
- specialty-specific narrative clauses

Governance principles:

- publish only demo-safe subsets
- keep full ontology and usage statistics internal
- track versioning for clinical review
- document role restrictions and approved phrase libraries
- review specialty packs with qualified clinicians before enterprise use

Do not expose ontology details beyond what is necessary for a demo experience.
