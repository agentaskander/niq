# Clinical Workflow Data Moat

Confidential internal material.

The long-term moat is not generic AI text generation. The moat is understanding how clinicians build patient stories:

- which symptoms are selected together
- which timing sequences matter
- which observations trigger reassessment or escalation
- how role scope changes narrative format
- which generated notes are accepted, edited, copied, or rejected
- which specialty workflows save measurable time

High-value data classes:

- WorkflowEvent selection sequences
- ClinicalStorySession timing and completion metrics
- NarrativeRevision edit-distance and acceptance patterns
- OntologyUsageStats co-selection clusters
- BetaFeedback adoption and safety feedback

No PHI should be collected for demo analytics. Optional contact information must be stored separately from clinical workflow sessions.
