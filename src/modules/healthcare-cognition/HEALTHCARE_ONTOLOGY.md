# Healthcare Ontology

This ontology is a demonstration taxonomy, not a clinical terminology system.

## Public-Safe Domains

- Care continuity
- Workflow state
- Documentation burden
- Role handoff
- Review readiness
- Interoperability friction
- Provenance visibility
- Specialty context

## Boundaries

The ontology avoids diagnosis, medication guidance, treatment selection, patient identifiers, and private scoring. It is suitable for investor and product demonstration only.
